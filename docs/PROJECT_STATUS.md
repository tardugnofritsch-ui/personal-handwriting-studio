# 原项目到公开工具的整理范围

原个人项目经历了 MX-Font 少样本生成、个人监督微调、风格优化、3500字扩充、真实样字优先、英数字符/等号修正、多字形试验和数学符号扩充。最终认可的是小幅柔和变形与白底A4排稿。

公开版沿用其模型架构、采样训练思想、轮廓构建与柔和参数，重写路径和输入接口，去除机器专属绝对路径、个人作业内容及私人字库。

| 环节 | 当前公开版 |
| --- | --- |
| 采集模板 | 可执行；扫描对齐需人工 |
| 单字切分 | 显式坐标裁切；不猜OCR标签 |
| 字体学习 | MX-Font推理、可选个人解码器微调 |
| 3500字 | 可输入自己的完整字表；没有捆绑预生成个人字库 |
| 导出 | TTF，真实样字优先，字符来源记录 |
| 五种写法 | 简单轮廓的温和几何变体；复合轮廓保持原状 |
| 手写稿 | 纯文本白底A4、PNG和图像PDF |
| 数学 | 输入已有Unicode符号；不支持通用公式布局 |
| 原网页应用 | 原项目使用 text2handwriting；本仓库未打包其网页应用 |
| 人工质量确认 | 必需；自动覆盖检查不能替代 |

待扩展：复合轮廓变体、真实多样字轮换、细笔后处理、数学公式布局、可视化标注、字体许可元数据输入、断点续训，以及网页前端。这些不作为v0.1的已完成功能宣传。
