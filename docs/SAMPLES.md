# 样本采集与检查

白纸、深色笔、均匀光照；扫描比带透视照片更容易处理。字应在给定的空白框内，避开字符标签和边框。模板不是自动透视校正工具。

建议先采20–50个字，覆盖左右、上下、包围、独体结构及常见偏旁；确认后补到更多样字。数字、英文字母、标点和数学符号单独采集。每字多次书写时保留不同文件，不要把重复样本伪装成不同字符。

手工裁切时，准备以下格式，图像为白底深色单字，清晰且不截断：

```json
[
  {"char": "你", "file": "U4F60-01.png"},
  {"char": "你", "file": "U4F60-02.png"},
  {"char": "好", "file": "U597D-01.png"}
]
```

`file` 相对于 manifest 所在目录，只允许该目录内的路径。切字会标准化为128×128、居中、最大104×104；这是模型输入规范，不是恢复原稿绝对字宽。原始样张应保留在本地以便追溯。

特别注意：整句 OCR 不能替代单字标签检查。逐字核对 Unicode、裁切框、邻字尖角和分离笔画。代码不会自动把“形近字”纠正成你想要的字。对小数点、引号等符号应观察标准化是否放大过多；需要自然大小时可直接提供保留统一画布比例的字形位图给 `font` 命令，不走 manifest 标准化路径。

多页采集使用不同输出目录。汇总时令路径相对于合并 manifest，并保留子目录；不要覆写 `manifest.json` 后丢掉前页标签。
