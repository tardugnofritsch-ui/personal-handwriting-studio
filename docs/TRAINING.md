# 学习、微调与几何变体

1. **少样本推理**：`learn --steps 0` 提取样字的风格特征，与结构字体的字符内容特征组合，使用既有预训练模型生成位图。没有进行新的梯度更新。
2. **个人微调**：`learn --steps N` 对解码器后段参数做真实梯度更新。样字监督包括像素、笔墨量与梯度差异；冻结教师输出提供结构、笔墨量和模糊度约束。按字符分组的10%验证与10%测试样字不参与训练或风格参考。最佳验证解码器会被恢复。
3. **几何后处理**：`variants` 从TTF轮廓生成轻微比例、倾斜及局部波形变化，不会学习更多笔迹，也不意味着五份真实手写样本。

本版本是从原项目提取并参数化的轻量训练路线。原实验的3500字多轮遍历、风格张量优化、OCR筛查、细笔校正、人工等号修复和复杂公式布局并未全部产品化。不能仅因工具执行成功就声称“完整复现了原个人字体”。

结构字体须覆盖样字和生成范围。模型与参考字体不同可能影响质量。先在小字表上检查未见字结构，再扩充。CPU/GPU浮点实现差异会影响训练结果，固定种子不承诺跨硬件训练逐字节一致；同环境下的排稿种子用于复现排版。

字体生成记录来源，但没有自动字体兜底。`audit` 检查映射和空轮廓，不等价于视觉确认。扫描质量、标注质量和样字代表性通常比增加训练步数更重要。

此版本每次 `learn` 都从用户指定的预训练模型开始；保存的 `personal.pt` 用于保留个人解码器与风格参数，暂不提供断点续训/独立重载推理命令。若补字，可重跑相同样本与目标字表，或追加自有字形后重建字体。
